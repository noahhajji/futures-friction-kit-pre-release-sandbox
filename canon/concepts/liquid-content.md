# Liquid content

Liquid content is content that dynamically adapts in real time across formats, platforms, contexts and users rather than existing as one fixed version.

- The shift is from information to context, from static to liquid. Competitive advantage depends less on simply making information available and more on understanding what matters in a given moment, for a given person, in a given situation.
- The quality of liquid content depends on context, data richness, inference and interpretation, which raises questions around privacy, misreading, manipulation and fairness.
- As organisations lose some control over static content in a more liquid digital ecosystem, the static 'artifact' of content is no longer where the value lies.
